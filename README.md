This repository serves as a personal log and structured collection of my solutions to various **Data Structures and Algorithms** problems. The problems are primarily sourced from LeetCode and encompass varying levels of difficulty. By solving these, I practice core computer science fundamentals designed to produce optimal, efficient, and clean code.

## 📁 Repository Structure

The repository is organized seamlessly where each folder corresponds to a specific programming challenge.

Example topics covered include:
- **Arrays & Strings** (e.g., Two Sum, Rotate Array, Container With Most Water)
- **Linked Lists** (e.g., Merge Two Sorted Lists, Intersection of Two Linked Lists)
- **Trees & Graphs** (e.g., Binary Tree Traversals, Lowest Common Ancestor, Balanced Binary Tree)
- **Dynamic Programming** (e.g., Coin Change, Longest Increasing Subsequence)
- **Sorting & Searching** (e.g., Binary Search, Sort Colors, Kth Largest Element)
